## Requisitos

- Windows 10/11 (64 bits)
- WSL2 habilitado (para RedTeamProV4)
- 4 GB de RAM mínimo

---

## Instalación

1. Descarga el instalador de la herramienta deseada.
2. Ejecuta como administrador.
3. Sigue las instrucciones del asistente.
